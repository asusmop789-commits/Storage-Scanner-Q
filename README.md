# 🖥️ Storage Scanner Ultimate V3.2.2 (Hardcore CLI)

Профессиональная консольная утилита для автоматической диагностики накопителей, вывода данных S.M.A.R.T. и подсчета реального объема памяти в обход маркетинговых уловок производителей.

## 🚀 Основные фичи
* **Аппаратный опрос S.M.A.R.T.** — мгновенная проверка здоровья дисков без прав администратора.
* **Глубокая классификация** — точное определение типов дисков (Внутренние SSD, жесткие диски HDD, а также накопители, подключенные через специальные USB-переходники).
* **Разоблачение маркетологов** — автоматический расчет «маркетинговой усушки» (разницы между десятичной системой заводов и двоичной системой Windows).
* **Cyberpunk CLI-анимация** — эффектный хакерский процесс сканирования секторов при запуске.
* **Авто-отчет** — автоматическая генерация красивого текстового файла `Drive_Report_V3.txt` прямо на Рабочий стол.

## 📁 Структура проекта
* `q.py` — исходный код утилиты на Python 3.
* `dist/q.exe` — готовый скомпилированный исполняемый файл для Windows (работает без установленного Python).

## 🛠️ Как запустить (Для пользователей)
1. Скачайте файл `q.exe`.
2. Перенесите его на Рабочий стол.
3. Запустите двойным кликом мыши.
4. После окончания сканирования изучите отчет. Нажмите `ENTER` для выхода.

## 💻 Сборка из исходников (Для разработчиков)
Если вы хотите изменить код и собрать свой `.exe`, вам понадобятся Python 3 и утилита `PyInstaller`:

```cmd
pip install pyinstaller
python -m PyInstaller --onefile q.py
```
После сборки новый файл появится в папке `dist/`.
